## 説明文（案）
名刺を撮って、端末の中で読み取り、暗号化したまま整理する名刺管理アプリです。

■ 守りを最優先
・名刺の氏名・会社・連絡先・画像は、端末内で暗号化してから保存・同期します。運営者のサーバーでも内容は読めません。
・文字の読み取り（OCR）、検索、重複の確認は端末の中で行います。
・AIは名刺の削除・統合・送信・共有を自分では行いません。外部AIを使うときは毎回、送る内容を表示して確認します（既定はオフ、氏名や会社名は伏せ字にして送信）。

■ スマホでもPCでも
・スマホで撮影・登録した名刺を、PCのブラウザで検索・編集できます。
・オフラインでも閲覧・編集でき、つながったときに同期します。同時に編集した場合は両方を残して選べます。

■ 人とのつながりを記録
・異動・転職の履歴、出会った場所や会話のメモ、タグ、フォロー予定。
・同姓同名を誤ってまとめない、理由付きの重複候補。

※ 復旧キーをなくし、すべての端末でデータを失うと復元できません。

## 審査メモ（両ストア共通）
- サインインはメールの確認コード方式。審査用のメールアドレス〔要準備〕。
- 名刺データは E2EE。運営者は内容を閲覧できない。
- 外部AIは既定オフ。サーバー側で API キーと規約確認フラグがそろった場合のみ選択肢が表示される。
