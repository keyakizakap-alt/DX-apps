# 開発ハーネス（自動テスト・仕様書チェック）

- ステータス: 完了
- 導入元: daily-useful-tools の `.claude/skills/repo-harness`

## 目的

自動テスト・失敗時の「直し方」の出力・仕様書の完了条件を、このリポジトリの開発の土台にする。

## スコープ

- やること: 最小テスト、仕様書チェッカー、仕様書の雛形、エージェント向けの指示
- やらないこと: 既存のテスト・設定ファイルの書き換え

## 完了条件

- [x] `npm test` が終了コード0で終わる
- [x] `npm run lint:specs` が終了コード0で終わる
- [x] `docs/specs/_TEMPLATE.md` が存在する
- [x] 完了条件のない仕様書を置くと `npm run lint:specs` が終了コード1で終わり、出力に `直し方:` を含む
